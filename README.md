# Proformas al Toque

App de proformas para INNOVA Equipos Gastronómicos: inventario de equipos, clientes y proformas en PDF con el formato de la empresa.

- Sitio estático (`index.html`), publicado en Vercel.
- Datos y cuentas en Supabase (proyecto `proformas-al-toque`). Solo entran los correos de la tabla `miembros`.
